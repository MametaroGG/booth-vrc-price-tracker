# Boopa v1.2.0

## 変更点
- 規格外の高額な記録がある場合も、通常の価格推移を見やすく表示。全価格表示への切り替えと履歴表示を追加しました。
- 最安値・比較価格の表示を整理し、記録価格と現在の販売割引を区別しました。
- BOOTHの表示言語に合わせ、日本語・英語・韓国語・簡体字・繁体字に対応しました。
- Chrome標準の国際化にも対応し、拡張機能名・説明を5言語で表示します（未対応言語は日本語）。ページ内UIは引き続きBOOTHの表示言語に追従します。
- 商品ページとショップページのレイアウトに対応。狭い表示幅で履歴の商品名を折り返し、日付・価格を読みやすくしました。
- 切り替えボタンの形とアニメーションを調整し、ショップの明暗配色に追従するようにしました。

## 配布ファイル
`boopa-v1.2.0-chrome-web-store.zip` は、manifest.jsonを直下に配置したChrome Web Store提出用パッケージです。手動で試す場合は展開し、Chromeの拡張機能画面から「パッケージ化されていない拡張機能を読み込む」で読み込めます。
